# Resume Bot 🤖📄

Bu oddiy **Telegram Bot**, siz haqingizdagi ma'lumotlarni (rezume shaklida) foydalanuvchiga taqdim etadi. Foydalanuvchi `/start` buyrug'ini yuborganda menyu paydo bo'ladi va u yerdan siz haqingizda turli ma'lumotlarni olishi mumkin: "About Me", "Skills", "Languages", "Contact Me".

## 📌 Xususiyatlari

- `About Me` — Surat va qisqacha o'zingiz haqingizda ma'lumot
- `Skills` — Bilim va texnologiyalar ro‘yxati
- `Languages` — Qaysi tillarni bilishingiz
- `Contact Me` — Ijtimoiy tarmoqlar va aloqalar

## 🛠 Texnologiyalar

- Til: `C#`
- Telegram Bot API: `Telegram.Bot`
- Platforma: `.NET`
